| 항목 | 방법 | 결과 |

## 확인하지 않은 것

- 파이썬 **3.10~3.12 실제 설치본**에서의 실행(인코딩 차이는 `-X utf8=0`으로 같은 기본값을 재현한 것).
- VS Code · Jupyter 화면, 가상환경 만들기(`python -m venv`)를 이 PC에서 직접 해 보는 것.
- 27회차 세 문제의 **프로그래머스 재채점**과 실패 원인(제출 코드 칸이 비어 있음). SQL 별칭(`AS TLNO`)이 없을 때 채점 결과.
- 백엔드 과정의 남은 단계(Spring Security · 종합)가 언제 이어지는지.
