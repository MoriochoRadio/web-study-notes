## 확인한 것 — Day 8

| 항목 | 방법 | 결과 |
|---|---|---|
| 청크 나누기 | 노트북 칸 0의 `split_text`를 그대로 실행 | 143자 → 50 · 10이면 4개(시작 0 · 40 · 80 · 120, 겹친 10글자 일치), 80 · 0이면 2개 — 저장된 출력과 같음. 10 · 10은 `ValueError`, 검사를 빼면 start가 0 → 0 → 0 |
| 문단 단위 분할 | `RecursiveCharacterTextSplitter(150, 30)`로 `lecture_policy.txt` | 640자 → 6조각, 4개가 "제N장"으로 시작. 같은 글을 `split_text(150, 30)`으로 자르면 첫 조각이 문장 중간에서 끊김. 전액 환불의 두 조건은 3번 조각에, 부분 환불 기준은 4번 조각에 있음 |
| 벡터 저장소 · Retriever | 키 환경변수를 지우고, 글자 2-gram을 세는 장난감 임베딩으로 | 문서 3개에 k=5 → 3개, 관련 없는 질문에도 k개(유사도 0.0으로 채움), 결과는 `Document`(id 있음, metadata `{}`), `as_retriever` → `VectorStoreRetriever` |
| 점수 기준 검색 | `as_retriever(search_type="similarity_score_threshold")` | 이 PC의 langchain-core 1.6.13 `InMemoryVectorStore`에서 `NotImplementedError`(`_select_relevance_score_fn` 미구현). `similarity_search_with_score`로 직접 거르는 함수는 동작 |
| RAG 체인 | LLM 자리에 받은 메시지를 그대로 돌려주는 가짜 | system 칸에 검색 문서 두 줄 + human 칸에 원래 질문. 딕셔너리로 invoke하면 `TypeError: expected string or bytes-like object, got 'dict'`, `itemgetter("question") | retriever`는 동작 |
| 카드의 다른 주장 | 같은 방식 | 프롬프트 변수 이름이 다르면 `KeyError`, 체인 안 딕셔너리는 `RunnableParallel`, `OpenAIEmbeddings`의 `tiktoken_enabled` 기본값 `True` |
| 17쪽 종합 참고 풀이 | 장난감 임베딩 + 가짜 LLM | `answer()` 함수 연결 확인. 전화번호 질문에 환불 · Q&A 문서가 붙는 것까지만(실제 답은 미확인) |

## 확인한 것 — 역량 진단 탭

| 항목 | 결과 |
|---|---|
| 두 자료 대조 | 자바 · SQL · 웹은 LMS 화면과 성적표의 오답 번호가 같다(16 · 15 · 15). 프런트엔드는 성적표 1차 34/50(오답 16), 붙여 준 화면은 다시 풀기 13/50(오답 37) — 두 번 다 틀린 13문항을 따로 표시 |
| 정답 검토 | 오답 62문항(프런트 1차 16 포함)의 LMS 정답을 하나씩 다시 따져 봄 — 고칠 정답은 없었다. 자바 Q49는 옮긴 글에서 `<` 기호가 잘려 보기를 알 수 없어 "알 수 없음"으로 적음 |
| 카드 연결 | 링크한 카드 id가 모두 실제로 있는지 만들 때 검사(없음 0). 노트에 있었는데 틀림 40 · 일부만 4 · 노트에 없던 개념 2(트리거 OLD/NEW · 커서) — 카드 본문을 키워드로 찾아 분류 |
| 문제 형태 통계 | 자바 코드 결과 문항 24개 중 12개 오답(개념 문장 26개 중 4개). "옳지 않은 것" 형에서 틀린 14문항(자바 3 · SQL 3 · 웹 8)은 모두 맞는 설명을 고름 — 보기마다 대조 |

## 확인하지 않은 것

- 실제 OpenAI 임베딩 · LLM 호출(요금 · 키). 노트북의 1536 · 검색 결과 · 답변은 저장된 그대로다. 노트북 마지막 칸(규정 문서 확장판)은 출력이 없어 답을 확인하지 못했다.
- 역량 진단의 "내 답"은 LMS 화면에 표시된 선택이다. 프런트엔드 1차 응시에서 무엇을 골랐는지는 성적표에 없어 1차만 틀린 3문항(Q7 · 9 · 37)은 "기록 없음"으로 적었다.
