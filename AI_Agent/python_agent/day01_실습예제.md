## Part 1. 변수와 연산자 (25분)

### 문제 1-1. 자기소개 변수 (기초)

```
저는 OOO이고, OO살이며, OO에 살고 있습니다.
```

### 문제 1-2. 원의 넓이 계산기 (기초)
반지름(radius)을 변수로 저장하고, 원의 넓이를 계산해 출력하세요. (원의 넓이 = 반지름 × 반지름 × 3.14)

### 문제 1-3. 쇼핑몰 할인 계산기 (도전)
가격(price)과 수량(quantity)을 변수로 저장하고 총액(total)을 계산하세요.
그리고 아래 두 가지를 비교·논리 연산자로 만들어보세요.
- `total`이 30000 이상이면 True가 되는 `is_discount`
- 수량이 3개 이상이면서 할인 대상이면 True가 되는 `is_special`

```python
price = 8000
quantity = 4
# total, is_discount, is_special 을 만들어 모두 출력하세요
```

# 2. books[0]["price"] >= 15000 형태로 각 책의 가격을 확인하세요
