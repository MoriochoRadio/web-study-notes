# Day 6-7 실습예제 — LangChain으로 실전 LLM 구성요소 다루기

## 진행 안내

- 개발 환경 : 순정 Python + venv 가상환경 + VS Code
- 아래 명령어는 모두 **VS Code 통합 터미널**(`` Cmd+` `` / `Ctrl+` `` `` )에서 실행합니다.

```bash
python -m venv myenv
source myenv/bin/activate      # Windows: myenv\Scripts\activate
pip install langchain langchain-core langchain-openai python-dotenv
```

- `.env` 파일을 만들고 `OPENAI_API_KEY=발급받은키` 를 저장해둔 뒤 시작합니다.
- 아래 문제들은 하나의 `.py` 파일에 이어서 작성해도 되고, Part별로 새 파일을 만들어도 됩니다.

## Part 4. Memory를 가진 대화형 체인

### 4-2.
`history = []` 상태에서 `"공포 영화 하나만 추천해줘"`를 `invoke()`하고, 결과를 `history`에 사용자 메시지·AI 메시지 형태로 각각 추가하세요.

## Part 5. 종합 실습 — Tool + Memory를 연계한 가계부 챗봇

> **💡 안내**: LLM이 스스로 도구를 판단해 실행하는 '에이전트(Agent)'는 Day 8에서 본격적으로 다룹니다.  
> 이번 실습에서는 **"정확한 계산은 Tool(`calculate`)에 맡기고, 계산 결과를 바탕으로 친절한 대화와 기억(Memory)은 체인(`chain`)이 담당하는"** 역할 분담 구조를 직접 코드로 구현합니다.

Part 1~4에서 만든 `llm`, Tool, Memory 패턴을 모두 활용해 아래 요구사항을 만족하는 미니 챗봇을 하나의 `.py` 파일로 완성하세요.

1. `calculate(expression: str) -> str` 사칙연산 Tool을 `@tool`로 작성하세요.
2. `("system", "너는 친절한 가계부 비서야. 지출 내역을 분석하고 조언해줘.")`, `MessagesPlaceholder("history")`, `("human", "{question}")`을 포함한 `chain`을 만드세요.
3. `history = []` 상태에서 **[Tool 계산 ➔ 챗봇 대화 ➔ Memory 저장]** 순서로 대화를 이어가세요.
   - **1턴 (지출 합계)**:
     - `calculate.invoke({"expression": "12000 + 4500"})`로 편의점·카페 지출 총액을 먼저 계산하세요.
     - 계산 결과를 질문에 포함해 `"편의점 12000원, 카페 4500원으로 총 {계산결과}원을 썼어. 지출 평가와 조언을 해줘."`를 `chain`에 호출하고, `history`에 사용자/AI 메시지를 추가하세요.
   - **2턴 (추가 지출 & 대화 기억 확인)**:
     - 1턴 결과에 5000원을 더한 수식을 `calculate.invoke()`로 계산하세요.
     - 같은 `history`를 전달하며 `"방금 총액에서 5000원을 더 써서 {새_계산결과}원이 되었어. 이번 달 예산 괜찮을까?"`를 호출해 이전 대화를 기억하고 답하는지 확인하세요.
4. (도전) 매 턴마다 `history`의 길이(메시지 개수: `len(history)`)를 출력해서, 대화가 길어질수록 다음 호출에 포함되는 메시지 수가 늘어나는지(2개 ➔ 4개) 확인하세요.
