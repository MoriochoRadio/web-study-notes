## 실행 환경과 다시 실행한 결과

- 노트북 메타데이터의 파이썬은 **3.15.0** — 교안 권장(3.10~3.12)보다 새 버전이다.
- 코드 칸을 꺼내 저장소 밖에서 파이썬 3.15.0으로 다시 실행했다. 17칸 중 15칸이 저장된 출력과 같았다.
  - **로또 번호 칸**은 무작위라 실행마다 다르다. `randint`를 여섯 번 부르는 방식이라 같은 번호가 나올 수 있다(다시 실행할 때 16 · 5 · 45가 각각 두 번 나온 목록이 있었다). 서로 다른 번호는 `random.sample(range(1, 46), 6)`.
  - **구구단 칸**의 저장된 출력은 while 부분이 `7 x 10 = 70`까지 10줄이다. 코드를 고친 뒤 그 칸을 다시 실행하지 않은 것으로, 지금 코드는 9줄을 찍는다. 사본은 수업 파일 그대로 두었다.
- 점수 분석 칸은 `enumerate`가 0부터이고 앞 문제의 `sort()` 뒤에 돌아, 교안 예시(`1번째 학생: 88점`)와 달리 `0번째 학생: 60점`부터 나온다 — 고친 코드는 [실습 03](../index.html#lab-03).

## 인코딩 — 3.15와 3.12 이하 Windows의 차이

Day 2 파일 칸(`open("memo.txt", "w")`)은 교안처럼 `encoding`을 적지 않았다. 파이썬 3.15는 기본이 UTF-8이라 `memo.txt`가 UTF-8로 저장되었지만, 3.12 이하 Windows는 기본이 cp949다. UTF-8 모드를 끈 실행(`python -X utf8=0`)으로 비교하니 같은 문장이 cp949로 저장되었고, UTF-8 파일을 cp949로 읽으면 `UnicodeDecodeError`가 났다. 점수 파일 칸처럼 `encoding="utf-8"`을 적으면 버전 · OS와 상관없이 같다. → [개념 08](../index.html#py-08)
