# 과제 풀이 — 일정 목록 조회 (2026-10-14)

> 선생님이 `CalController` 맨 아래에 남긴 과제
> ```
> //과제
> //일정 목록 조회
> // 받을 파라미터: year, month, date
> // 응답페이지: calboardlist.html
> ```
> 그리고 `calboardlist.html`에는 `목록 내용: checkbox, mdate, title, regdate` 한 줄만 있었다.

---

## 1. 한 줄 요약

**달력에서 날짜 숫자를 누르면 → 그날 등록된 일정들을 표로 보여 준다.**

```
달력 화면                Controller              Service                    Mapper(SQL)                 DB
──────────             ─────────────          ─────────────              ─────────────               ─────
"14" 클릭  ──요청──▶  calBoardList()  ──▶  calBoardList()     ──▶   calBoardList          ──▶  calboard
year=2026              (값 받기,             (2026+"10"+"14"          WHERE id=#{id}
month=10                없으면 오늘)          = "20261014"             AND MDATE LIKE
date=14                                       Map에 담기)              '20261014%'
                                                                                         ◀── 그날 일정 행들
calboardlist.html ◀── model에 list 담아 ◀── List<CalDto> 반환 ◀──────────────────────────
(표로 그리기)          "calboard/calboardlist"
```

선생님이 이미 만들어 둔 것: **Mapper의 SQL(`calBoardList`)과 인터페이스 메서드**.
내가 만든 것: **달력 링크 → Controller → Service → 화면** 네 칸.

## 3. 하나씩 보기

### ① 달력 — 날짜 숫자에 링크 걸기 (`calendar.html`)

```html
<!-- 전: 누르면 아무 데도 안 감 -->
<a href="#" th:text="${i}" class="d"></a>

<!-- 후: 그날의 목록으로 -->
<a th:href="@{/schedule/calboardlist(year=${calMap.year},month=${calMap.month},date=${i})}"
   th:text="${i}" class="d"></a>
```

- `@{주소(이름=값, 이름=값)}` — Thymeleaf가 **쿼리스트링을 자동으로** 만들어 준다.
  결과: `/schedule/calboardlist?year=2026&month=10&date=14`
- 바로 옆 "추가" 링크(`addcalboardform`)와 **똑같은 모양**이다. 주소만 다르다.

### ② Controller — 요청 받기 (`CalController.java`)

```java
@GetMapping("/calboardlist")
public String calBoardList(String year, String month, String date,
                           @RequestParam(defaultValue = "hk") String id,
                           Model model) {
    // 값 없이 들어오면(null) 오늘 날짜로
    LocalDate today = LocalDate.now();
    if (year == null)  year  = today.getYear() + "";
    if (month == null) month = today.getMonthValue() + "";
    if (date == null)  date  = today.getDayOfMonth() + "";

    List<CalDto> list = calService.calBoardList(id, year, month, date);

    model.addAttribute("list", list);
    model.addAttribute("year", year);   // 화면 제목·링크용
    model.addAttribute("month", month);
    model.addAttribute("date", date);
    model.addAttribute("id", id);
    return "calboard/calboardlist";
}
```

- **매개변수 이름 = 쿼리스트링 이름**이면 스프링이 알아서 넣어 준다 (`?year=2026` → `String year`).
  `calendar(Model model, String year, String month)`와 같은 방식.
- 값이 없으면 `null` → 그대로 쓰면 `"null" + ...`이 되어 아무것도 안 나온다. 그래서 오늘 날짜로 채운다.
  **Controller에서 채우는 이유**: 화면 제목(`○년 ○월 ○일`)과 실제 조회가 **같은 날짜**를 써야 하니까.
  (처음엔 Service에서 채웠더니 화면 제목이 "null년 null월 null일"로 나왔다.)
- `id`는 왜 `@RequestParam(defaultValue = "hk")`?
  → 선생님 SQL이 `WHERE id = #{id}`로 **누구의 일정인지**를 꼭 묻는다. 그런데 이 프로젝트에는 **아직 로그인이 없다.**
  그래서 주소에 `id`가 없으면 수업 데이터의 아이디 `hk`를 쓰게 했다. (`?id=다른아이디`를 붙이면 그 사람 것)
  **로그인이 붙으면** 이 줄만 세션의 아이디로 바꾸면 된다 (10번 프로젝트의 `session.getAttribute("mdto")`처럼).

### ③ Service — 8자리 날짜 만들기 (`CalServiceImp.java`)

```java
public List<CalDto> calBoardList(String id, String year, String month, String date){
    String yyyyMMdd = year + isTwo(month) + isTwo(date);   // "2026" + "10" + "14" = "20261014"

    Map<String, String> map = new HashMap<>();
    map.put("id", id);
    map.put("yyyyMMdd", yyyyMMdd);
    return calMapper.calBoardList(map);
}
```

**왜 8자리?** DB의 `mdate`는 `yyyyMMddHHmm` **12자리 문자열**이다 (일정 추가에서 `insertCalBoard`가 이렇게 만든다).

| 저장된 mdate | 뜻 |
|---|---|
| `202610140905` | 2026-10-14 09:05 |
| `202610141430` | 2026-10-14 14:30 |

"10월 14일의 일정" = **앞 8자리가 `20261014`인 것**. 그래서 SQL이 `MDATE LIKE CONCAT('20261014', '%')` — "20261014로 **시작하는**" 행을 찾는다.

**왜 `isTwo`?** 9월 5일을 그냥 붙이면 `"2026" + "9" + "5"` = `"202695"` (6자리) → 아무것도 못 찾는다.
`isTwo("9")` = `"09"`라서 `"20260905"` (8자리)가 된다. **일정 추가(insertCalBoard)에서 쓰던 그 메서드를 그대로 재사용**했다.

**왜 Map?** Mapper 인터페이스가 `calBoardList(Map<String,String> map)`으로 되어 있다. SQL에 값이 두 개(`#{id}`, `#{yyyyMMdd}`) 필요하니 Map 하나에 담아 보낸다.
**Map의 key 이름 = SQL의 `#{...}` 이름** — 하나라도 다르면 그 자리에 `null`이 들어가 결과가 0개가 된다.

### ④ 화면 — 표로 그리기 (`calboardlist.html`)

```html
<tr th:if="${#lists.isEmpty(list)}">            <!-- 일정이 없으면 -->
    <td colspan="4">등록된 일정이 없습니다.</td>
</tr>
<tr th:each="dto:${list}">                       <!-- 있으면 한 줄씩 -->
    <td><input type="checkbox" name="seq" th:value="${dto.seq}"/></td>
    <td th:text="${#strings.substring(dto.mdate,0,4)} + '-' + ... "></td>  <!-- 202610140905 → 2026-10-14 09:05 -->
    <td th:text="${dto.title}"></td>
    <td th:text="${#dates.format(dto.regdate,'yyyy-MM-dd')}"></td>
</tr>
```

| 쓴 것 | 하는 일 |
|---|---|
| `layout:decorate="~{layouts/layout}"` + `layout:fragment="content"` | 다른 화면과 같은 머리·꼬리(메뉴, 저작권 줄) 입히기 |
| `th:each="dto:${list}"` | 리스트를 한 줄씩 (JSTL의 `c:forEach`) |
| `#lists.isEmpty(list)`, `#lists.size(list)` | 비었는지 / 몇 개인지 |
| `#strings.substring(문자열, 시작, 끝)` | 12자리 `mdate`를 잘라 `2026-10-14 09:05` 모양으로 |
| `#dates.format(날짜, '패턴')` | `regdate`(Date 객체)를 `2026-10-14`로 |
| 체크박스 `name="seq" value="${dto.seq}"` | **다음 단계(여러 개 삭제)** 준비. 선생님 Mapper에 `calMulDel`(seq 여러 개 → `IN (...)`)이 이미 있다 |
| 맨 위 "전체 선택" 체크박스 + `allSel()` | 누르면 아래 체크박스 전부 같이 체크 |

아래에 **일정 추가**(그날 날짜가 미리 골라진 폼)·**달력으로 돌아가기** 링크를 두었다.

## 5. 스스로 확인해 보기

1. `isTwo` 없이 `year + month + date`로 만들면 10월 14일은 찾을까? 9월 5일은?
   → 10월 14일은 `"20261014"`라 우연히 맞는다. 9월 5일은 `"202695"`가 되어 **못 찾는다.**
2. Map에 `map.put("ymd", yyyyMMdd)`로 넣으면?
   → SQL은 `#{yyyyMMdd}`를 찾는데 그런 key가 없어 `null`이 들어간다. `CONCAT(NULL, '%')`는 `NULL`이라
     `MDATE LIKE NULL`은 어떤 행에서도 참이 아니다 → 오류 없이 결과 0개. **key 이름 = `#{}` 이름.**
3. SQL을 `LIKE CONCAT(#{yyyyMMdd}, '%')` 대신 `= #{yyyyMMdd}`로 하면?
   → `mdate`는 12자리라 8자리와 **같을 수가 없다** → 항상 0개. "~로 시작"은 `LIKE '값%'`.
4. 로그인이 생기면 어디를 바꾸나?
   → Controller의 `@RequestParam(defaultValue = "hk") String id` 대신 세션에서 아이디를 꺼낸다. Service·Mapper는 그대로.
