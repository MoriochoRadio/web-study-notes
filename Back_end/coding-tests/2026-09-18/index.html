약수의 합

약수는 쌍으로 찾고, 완전제곱수의 제곱근은 한 번만 더한다.

2026-09-18 · 16회차 · 미응시 보충 학습. 동료 자료로 문제를 확인한 뒤 별도로 작성한 풀이다. 본인 제출 PASS 기록은 없다.

문제 원문 · 별도 보충 노트

JAVA
class Solution {
    public int solution(int n) {
        int sum = 0;
        for (int divisor = 1; divisor <= n / divisor; divisor++) {
            if (n % divisor != 0) continue;
            sum += divisor;
            int pair = n / divisor;
            if (pair != divisor) sum += pair;
        }
        return sum;
    }
}

1~n 전수 탐색도 제한 안에서 충분하다. 위 풀이는 d와 n/d를 함께 더하므로 O(√n)이다. pair != divisor로 제곱근 중복을 막는다. n=0이면 반복이 없으므로 0이다.

로컬 검증
0 → 0 / 1 → 1 / 5 → 6 / 12 → 28 / 36 → 91 / 3000 → 9360
허용 범위 0~3000: 독립적으로 만든 기대값과 3,001개 비교

최댓값 구하기

DATETIME의 최댓값이 가장 늦게 들어온 시각이다.

2026-09-18 · 16회차 · 미응시 보충 학습. 참고 문서의 채점 결과는 본인의 결과로 기록하지 않는다.

문제 원문 · 별도 보충 노트

SQL
SELECT MAX(DATETIME) AS 시간
FROM ANIMAL_INS;

GROUP BY 없이 전체 행을 집계한다. 최댓값이 중복되어도 결과는 한 행이다. 이름·ID를 함께 SELECT하면 어느 행의 값인지 불명확해진다. 빈 집합의 MAX 결과는 NULL이다.
