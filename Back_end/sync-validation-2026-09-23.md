## 범위의 한계

07의 Controller에는 목록 메서드만 있다. DAO·Service·Mapper에 SQL이 있다는 이유로 등록·상세·수정·삭제 화면까지 완성됐다고 표시하지 않았다. 해당 쓰기 작업은 이번 정리에서 실행하지 않았다.

Java의 로컬 정답 풀이 검증은 프로그래머스 재채점이나 FAIL 제출 코드의 재현이 아니다. SQL 검증도 별도 임시 데이터에 대한 확인이다. GitHub Pages는 학습 HTML을 제공하며 JSP 서버를 실행하지 않는다.
