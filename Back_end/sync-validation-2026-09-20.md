웹 실행 검사는 별도 Tomcat 인스턴스와 임시 DB를 사용했다. 기존 MVC1의 접속 클래스만 테스트 사본에서 임시 DB로 연결했고, DAO·JSP 처리 코드는 그대로 검사했다. 임시 DB를 삭제하고 테스트 서버를 종료했다. 기존 hk의 회원·구매·게시글 행 수는 검사 전후 동일했다.

MVC2 전체 전환, 잘못된 입력, 모든 CRUD 실패 경로를 검증한 결과는 아니다. 원본에 남은 분기·입력 검증·트랜잭션 판정 문제는 대조 문서에 기록했다. 코딩테스트는 프로그래머스에 제출하거나 본인의 PASS 이력으로 등록하지 않았다.

정적 웹은 저장소의 DOM·내부 링크·프런트엔드 및 백엔드 인벤토리 검사로 확인한다. 웹 배포 후 실제 공개 페이지도 확인한다.
